# PClaneR

Shiny-приложение для планирования 96-луночных плашек ПЦР-РВ для SNP-детекции.

## Запуск

```r
install.packages(c("shiny", "bslib", "DT", "openxlsx", "remotes"))
remotes::install_github("kablag/shinyMolBio")
shiny::runApp()
```

Файл `data/kits.xlsx` содержит профили: каждый лист — один профиль, каждая
строка листа — набор. Обязательные столбцы: «Краткое название», «Та» (или `Ta`)
и «Каналы». Один и тот же набор можно включать в разные профили, повторив его
на соответствующих листах.

На вкладке «Образцы и профили» образцы назначаются профилям отметками в таблице.
Алгоритм резервирует лунки под три типа ПКО (wt, h, m) и ОКО, затем размещает
максимально возможное число образцов сразу на всех наборах профиля. Внутренние
лунки имеют приоритет, а общие числа повторов задаются на вкладке плашек.
Для разных температур отжига создаются отдельные серии плашек; при переполнении
автоматически создаётся следующая плашка той же серии.
В режиме «По наборам» приоритет у сохранения всех образцов одного набора на
одной плашке: сначала плашки делятся между наборами, а образцы одного набора
переносятся на следующую плашку только если этот набор целиком не помещается.
Для ручной раскладки создайте пустую плашку, выделите на ней область и выберите
профиль с набором. В область попадут только ещё не распределённые реакции;
сводка на первой вкладке показывает размещённые и оставшиеся повторы.
Технические повторы располагаются рядом. Итог можно поправить кликами по
интерактивной плашке и выгрузить в XLSX.

Доступны горизонтальное и вертикальное направления. Режим «По наборам» начинает
каждый набор с новой строки/колонки, а «Сплошное» заполняет лунки последовательно.
При заполнении нескольких рядов/колонок их можно располагать рядом или зеркально
от краёв к центру. Внутри набора сначала идут образцы, затем ПКО и ОКО.

## Экспорт на приборы

- Innova XLSX создаётся из `data/innova.xlsx`: образцы — `UN`, ПКО — `PC`,
  ОКО — `NC`; имена образцов и контролей сохраняются такими же, как в приложении.
- Bio-Rad CSV использует типы `Unknown`, `Positive Control` и `NTC`. Его следует
  импортировать в CFX Manager через Plate Editor → Spreadsheet View/Importer.
- Прямой PLTD не формируется: PLTD является зашифрованным контейнером и зависит
  от ключа установленного экземпляра CFX Manager.
