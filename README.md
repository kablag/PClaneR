# PClaneR

Shiny-приложение для планирования 96-луночных плашек ПЦР-РВ для SNP-детекции.

## Запуск

```r
install.packages(c("shiny", "bslib", "DT", "openxlsx", "remotes"))
remotes::install_github("kablag/shinyMolBio")
shiny::runApp()
```

При первом запуске создаётся `data/kits.xlsx`. В нём одна строка соответствует
одному набору. Справочник также можно редактировать и заменять из интерфейса.

Алгоритм резервирует лунки под три типа ПКО (wt, h, m) и ОКО, затем размещает максимально возможное
число образцов сразу на всех выбранных наборах. Внутренние лунки имеют приоритет,
а общие для выбранных наборов числа повторов задаются на вкладке планирования.
Технические повторы располагаются рядом. Итог можно поправить кликами по
интерактивной плашке и выгрузить в XLSX.

Доступны горизонтальное и вертикальное направления. Режим «По наборам» начинает
каждый набор с новой строки/колонки, а «Сплошное» заполняет лунки последовательно.
При заполнении нескольких рядов/колонок их можно располагать рядом или зеркально
от краёв к центру. Внутри набора сначала идут образцы, затем ПКО и ОКО.

## Экспорт на приборы

- Innova XLSX создаётся из `data/innova.xlsx`: образцы — `UN`, ПКО — `PC`,
  ОКО — `NC`; имена образцов и контролей сохраняются такими же, как в приложении.
- Bio-Rad CSV использует типы `Unknown`, `Positive Control` и `NTC`. Его следует
  импортировать в CFX Manager через Plate Editor → Spreadsheet View/Importer.
- Прямой PLTD не формируется: PLTD является зашифрованным контейнером и зависит
  от ключа установленного экземпляра CFX Manager.
